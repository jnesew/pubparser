# pubparser

A small, safe, permissively licensed EPUB toolkit focused on structural correctness, extraction, inspection, and transformation without becoming a rendering engine.

The project is Python-first and treats EPUB files as untrusted input. The core aims to use only the Python standard library.

## Status

Early development. The initial `0.1` target is secure EPUB reading, inspection, navigation, text extraction, diagnostics, and conservative Project Gutenberg normalization.
